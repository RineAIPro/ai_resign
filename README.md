# 离职交接助手

一个基于 Flask 的离职交接管理工具，帮助即将离职的员工系统化地整理和交接工作内容，支持 AI 辅助生成文档，一键导出交接报告。

## 功能特性

### 公司管理
维护多家公司的基本信息，支持离职倒计时、交接进度跟踪。每家公司独立管理，切换方便。

### 项目管理
- 按模块/子模块组织项目，支持无限层级嵌套
- 记录项目名称、版本号、状态、技术栈、Git 地址、项目简介
- 填入项目地址后，AI 自动生成技术栈、Git 地址和简介
- AI 基于模板生成各项目的交接文档，保存至项目目录的 `jiaojie/` 子文件夹
- 支持导出项目清单为独立静态 HTML 文件，双击即可查看，方便分享给接手人

### 交接信息
- **账号交接** — 记录需交接的系统和平台账号（不含密码明文）
- **待办事项** — 管理交接期间的待办任务，按优先级分类
- **联系人管理** — 记录对接人和接手人信息及接手范围
- **交接日程** — 时间线管理交接节点，已完成/待进行状态一目了然

### 报告导出
勾选需要包含的章节，一键生成完整交接报告：
- 支持 Word (.docx) 和 Markdown (.md) 两种格式
- 可自定义文件名和保存目录
- 导出时自动复制各项目的 AI 交接文档到报告同目录，按模块层级分文件夹

### AI 集成
支持 Claude / DeepSeek / GLM 等多种 AI 提供商，可配置 API Key、Base URL、模型名称。AI 功能包括：
- 自动分析项目结构，生成技术栈和简介
- 基于模板生成项目交接文档
- 支持自定义交接文档模板

## 演示预览

项目包含一个独立的演示原型文件，无需启动服务器即可预览界面效果：

```bash
# 直接在浏览器中打开
prototype.html
```

演示原型展示了完整的功能界面，包括公司选择、项目管理、交接信息、设置面板等，方便快速了解工具的功能和交互方式。

## 技术栈

- **后端**：Python 3 + Flask
- **数据库**：SQLite（运行时自动生成，无需手动配置）
- **前端**：原生 HTML / CSS / JS，无框架依赖
- **AI 集成**：通过 Anthropic API 协议兼容多家提供商

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

依赖包括：Flask、httpx、python-docx、GitPython

### 2. 配置

复制示例配置文件并填入你的信息：

```bash
cp config.example.json config.json
```

配置项说明：

| 配置项 | 说明 |
|--------|------|
| `ai_enabled` | 是否启用 AI 功能 |
| `ai_api_key` | AI 提供商的 API Key |
| `ai_base_url` | API 地址，可改为代理/中转地址 |
| `ai_model` | 使用的模型名称 |
| `export_format` | 默认导出格式 |
| `export_dir` | 默认导出目录 |
| `font_scale` | 界面字体缩放比例 |

### 3. 启动

```bash
python app.py
```

Windows 用户可双击 `start.bat` 启动。

启动后会自动打开浏览器访问 `http://localhost:5000`。

## 导出说明

### 交接报告（Word / Markdown）

在主页面点击"生成报告"，勾选需要包含的章节，选择格式、文件名和保存目录，点击"生成并导出"。文件保存到指定目录，同时各项目的 AI 交接文档会按模块层级复制到报告同目录的子文件夹中。

导出目录结构示例：
```
保存目录/
  ├── 离职交接报告_某某公司_20260513.docx
  └── 离职交接报告_某某公司_20260513_项目交接文档/
        ├── 前端项目/
        │     └── 用户中心/
        │           ├── 交接1.md
        │           └── 交接2.md
        └── 后端服务/
              └── 推送服务/
                    └── 交接文档.md
```

### 项目清单（HTML）

在项目管理页面点击"导出HTML"，会在新标签页打开一个独立静态 HTML 页面。该页面：
- 内嵌所有 CSS 和数据，无外部依赖
- 支持模块折叠/展开
- Git 地址可点击跳转
- 响应式布局，移动端可查看
- 可通过 `Ctrl+S` 保存到本地分享

## 注意事项

- `config.json` 包含 API 密钥，已在 `.gitignore` 中过滤，请勿上传到公开仓库
- `data.db` 为运行时自动生成的数据库文件，已在 `.gitignore` 中过滤
- AI 交接文档生成后保存在各项目目录的 `jiaojie/` 子文件夹下
- 自定义交接文档模板放在 `resign_doc/` 目录下，文件名为 `.md` 格式
